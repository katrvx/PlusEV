# React Bits components

`AnimatedContent.tsx` and `Magnet.tsx` are adapted from [React Bits](https://github.com/DavidHDev/react-bits), pinned to commit `4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4`.

React Bits is copyright David Haz and is distributed under the [MIT + Commons Clause license](https://github.com/DavidHDev/react-bits/blob/4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4/LICENSE.md). The components remain source files in this project and are used as part of the PlusEV interface. They are not distributed as a standalone component library.

The PlusEV adaptations are limited to the accessibility and product needs described in each source file: explicit motion disabling, reduced-motion and coarse-pointer safeguards, a visible server-rendered fallback, bounded pointer movement, and cleanup-safe event handling.
